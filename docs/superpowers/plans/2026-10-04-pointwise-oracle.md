**Goal:** Test whether `layer_certify`'s `equality` and `taco` clause families admit exactly the layer orders an independent, exact, connectivity-derived oracle admits, on sampled subsets of the SAT-certified dense `lizard` arrangement.

**Architecture:** Two arms compared as *sets* of total orders. The independent arm (`stacks.py`) decides an order from one uniform rule — nothing may lie between a crease's two faces — evaluated exactly at one rational sample per sub-segment, which is exhaustive because the covering set changes only at a clip endpoint. The production arm (`restrict.py`) restricts `layer_certify.clauses(cons)` to the subset and evaluates it. Both are driven over two subset populations: neighbourhoods where production emits a constraint (soundness) and neighbourhoods where it emits none (completeness).

```python
def test_breakpoints_bound_constant_cover():
    """THE load-bearing claim (spec section 2.1): one sample per sub-segment is
    EXHAUSTIVE, not approximate, because the covering set changes only at a
    clip endpoint. Measured, not asserted: the cover must agree at three
    distinct interior points of every sub-segment."""
    seg = ((F(0), F(0)), (F(6), F(0)))
    polys = {
        7: _square(1, -1, 3, 1),
        8: _square(2, -1, 5, 1),
        9: _square(4, -1, 6, 1),
    }
    others = (7, 8, 9)
    cuts = stacks.breakpoints(seg, polys, others, K)
    assert len(cuts) >= 4, cuts
    for t_lo, t_hi in zip(cuts, cuts[1:]):
        w = t_hi - t_lo
        probes = [t_lo + w * F(1, 4), t_lo + w * F(1, 2), t_lo + w * F(3, 4)]
        covers = {stacks.covering(seg, t, polys, others, K) for t in probes}
        assert len(covers) == 1, (
            f"cover is NOT constant on ({t_lo}, {t_hi}): {covers}. The "
            f"breakpoint set is incomplete, so one sample per sub-segment "
            f"would be a sampling approximation rather than exhaustive")


def test_coarsened_breakpoints_break_the_completeness_gate():
    """The refusal demonstration for the gate above: with the interior cuts
    removed, the cover is provably NOT constant, so the gate must fail. A gate
    never shown to fail is a gate nobody has tested."""
    seg = ((F(0), F(0)), (F(6), F(0)))
    polys = {7: _square(1, -1, 3, 1)}
    others = (7,)
    coarse = (F(0), F(1))
    constant = True
    for t_lo, t_hi in zip(coarse, coarse[1:]):
        w = t_hi - t_lo
        probes = [t_lo + w * F(1, 4), t_lo + w * F(1, 2), t_lo + w * F(3, 4)]
        covers = {stacks.covering(seg, t, polys, others, K) for t in probes}
```

```python
"""The pointwise oracle: does the GEOMETRY permit this layer order?

Spec: `docs/superpowers/specs/2026-10-04-pointwise-oracle-design.md` section 2.

THIS MODULE IMPORTS NO PRODUCTION CODE, BY DESIGN -- it is the independent arm
of the comparison, and `test_stacks.py::test_no_production_imports` asserts the
absence structurally, because independence resting on a convention is not
independence.

THE RULE, and where it comes from. A crease JOINS two faces: the paper is
continuous across it, so nothing can pass between them. Therefore, at every
point of a folded crease image, the crease's two faces must be ADJACENT in the
stack of faces covering that point. That is derived from physical connectivity,
not from Akitaya-Demaine-Ku's family taxonomy, which is what makes it an
independent reading of the same condition. It subsumes all three families:
  * a face between a crease's two halves IS taco-tortilla;
  * two creases interleaving IS taco-taco, since interleaving necessarily
    places one crease's face between the other's pair;
  * tortilla-tortilla (a pair's order being constant across its overlap) is
    structural in `layer_order`, which carries ONE variable per face pair
    rather than one per cell, so it cannot vary by construction.

WHY ONE SAMPLE PER SUB-SEGMENT IS EXHAUSTIVE. The set of faces covering a
crease changes only where some face's clip span starts or ends. `breakpoints`
returns exactly those parameter values, so the covering set is invariant on
each resulting interval and one exact rational sample decides the whole
interval. There is no sampling density parameter and no sampling error.
`test_breakpoints_bound_constant_cover` MEASURES this rather than assuming it,
and `test_coarsened_breakpoints_break_the_completeness_gate` shows the check
can fail.
"""
from dataclasses import dataclass

import geom


@dataclass(frozen=True)
class Site:
    """One sub-segment of one crease, with the faces that cover it.

    `cover` holds the candidate INTRUDERS only -- `fa` and `fb` are excluded,
    since the question is what lies between them. `t_lo`/`t_hi` are carried for
    witness reporting and take no part in the decision.
    """
    fa: int
    fb: int
    cover: frozenset
    t_lo: object
    t_hi: object


def point_at(seg, t):
    """The point at parameter `t` along `seg`."""
    (x0, y0), (x1, y1) = seg
    return (x0 + t * (x1 - x0), y0 + t * (y1 - y0))


def breakpoints(seg, polys, others, K):
    """Parameter values along `seg` at which the covering set can change.

    Returns the segment's own ends together with every in-range clip-span
    endpoint, sorted and deduplicated. See the module docstring for why this
    makes one sample per interval exhaustive.
    """
    zero, one = K.conv(0.0), K.conv(1.0)
    cuts = {zero, one}
    for x in others:
        span = geom.clip_seg(seg, polys[x], K)
        if span is None:
            continue
        for t in span:
            if zero <= t <= one:
                cuts.add(t)
    return tuple(sorted(cuts))


def covering(seg, t, polys, others, K):
    """Faces in `others` whose STRICT interior contains `point_at(seg, t)`.

    Strict, not closed: a face whose BOUNDARY runs along the crease is not
    threading the fold and so is not an intruder. Under exact rational
    arithmetic "strictly inside" has exactly one meaning, so this imports no
    epsilon choice -- the decision rests on physics, not on a tolerance.
    """
    p = point_at(seg, t)
    return frozenset(x for x in others
                     if geom.strictly_inside(p, polys[x], K))


def sites(creases, polys, subset, K):
    """Every (crease, sub-segment) pair inside `subset`, with its intruders.

    `creases` is a sequence of `(fa, fb, seg)`. A crease with a face outside
    `subset` is a REFUSAL, not a skip: a caller that filters wrongly would
    otherwise get a quietly smaller population and a vacuously clean result.
    """
    out = []
    for fa, fb, seg in creases:
        if fa not in subset or fb not in subset:
            raise ValueError(
                f"crease ({fa}, {fb}) has a face outside the subset "
                f"{sorted(subset)}. Filter with `restrict.creases_in` before "
                f"calling `sites`; skipping it here would shrink the "
                f"population silently.")
        others = tuple(sorted(subset - {fa, fb}))
        cuts = breakpoints(seg, polys, others, K)
        for t_lo, t_hi in zip(cuts, cuts[1:]):
            mid = (t_lo + t_hi) / 2
            out.append(Site(fa, fb, covering(seg, mid, polys, others, K),
                            t_lo, t_hi))
    return tuple(out)


def active(sites_tuple):
    """Sites with at least one candidate intruder.

    A site with an empty cover can never yield a violation, so the enumeration
    skips it. `sites` still returns it, so the driver can report how much
    geometry was examined against how much of it could carry a constraint --
    an agreement is only as broad as the population it was taken over.
    """
    return tuple(s for s in sites_tuple if s.cover)


def violations_for_order(sites_tuple, order):
    """Sites where some face lies strictly between the crease's two faces.

    `order` is the stack TOP-TO-BOTTOM, so `order[0]` is topmost and "between"
    is just "index strictly between". All the geometry is already in
    `Site.cover`; this step is integer comparison, which is what lets the
    caller run it over every permutation cheaply.
    """
    pos = {f: i for i, f in enumerate(order)}
    out = []
    for s in sites_tuple:
        ia, ib = pos[s.fa], pos[s.fb]
        lo, hi = (ia, ib) if ia < ib else (ib, ia)
        between = tuple(sorted(x for x in s.cover if lo < pos[x] < hi))
        if between:
            out.append((s, between))
    return tuple(out)


def accepts(sites_tuple, order):
    """No site has anything between its crease's two faces."""
    return not violations_for_order(sites_tuple, order)
```

```python
import layer_certify                   # noqa: E402
import restrict                        # noqa: E402


class _C:
    """A stand-in Clause: the real one is a frozen dataclass, and these tests
    need only the three fields `restricted_clauses` and `clause_accepts` read."""

    def __init__(self, family, variables, flips):
        self.family = family
        self.variables = variables
        self.flips = flips
        self.prov = "test"


def test_restricted_clauses_keeps_only_fully_interior_clauses():
    """Both directions matter. Dropping a clause that IS interior would weaken
    the production arm and manufacture agreement; keeping one that is not would
    ask the oracle about a face it cannot see."""
    inside = _C("equality", ((0, 1), (0, 2)), (False, False))
    straddling = _C("equality", ((0, 1), (0, 9)), (False, False))
    outside = _C("equality", ((8, 9), (7, 9)), (False, False))
    got = restrict.restricted_clauses((inside, straddling, outside),
                                      frozenset({0, 1, 2}))
    assert got == (inside,), got


def test_order_to_rel_matches_layer_certifys_convention():
    """`layer_certify._satisfied` documents `rel[(lo, hi)] is True` as "lo
    above hi" (:143). `order[0]` is topmost, so above means a SMALLER index."""
    rel = restrict.order_to_rel((2, 0, 1))
    assert rel[(0, 1)] is True          # 0 precedes 1, so 0 is above 1
    assert rel[(0, 2)] is False         # 2 precedes 0, so 0 is NOT above 2
    assert rel[(1, 2)] is False
    assert set(rel) == {(0, 1), (0, 2), (1, 2)}


def test_clause_accepts_evaluates_equality_both_ways():
    """`equality` is `vals[0] == vals[1]` (layer_certify.py:145-146). With
    `_lit(x, f) = ((x, f), False) if x < f else ((f, x), True)`, the clause
    "face 2 is on the same side of 0 as of 1" is ((0, 2), True), ((1, 2), True).
    """
    c = _C("equality", ((0, 2), (1, 2)), (True, True))
    # 2 above both 0 and 1: both literals true -> equal -> satisfied
    assert restrict.clause_accepts((c,), restrict.order_to_rel((2, 0, 1)))
    # 2 between 0 and 1: one literal true, one false -> violated
    assert not restrict.clause_accepts((c,), restrict.order_to_rel((0, 2, 1)))


def test_transitivity_family_rejects_a_cyclic_relation():
    """GATE (spec section 6.2). `transitivity` is vacuous on a total order, so
    the enumeration never tests it; this is the correctly-sized substitute. The
    predicate is `not (rab == rbc and rac != rab)` (layer_certify.py:147-149).
    """
    cyc = {(0, 1): True, (1, 2): True, (0, 2): False}   # 0>1>2 but 2>0
    vals = (cyc[(0, 1)], cyc[(1, 2)], cyc[(0, 2)])
    assert not layer_certify._satisfied("transitivity", vals), (
        "a cyclic triple must violate the transitivity family")
    acyc = (True, True, True)
    assert layer_certify._satisfied("transitivity", acyc)


def test_classify_uses_the_restricted_set_not_global_membership():
    """A clause whose variables leave the subset says nothing the oracle can
    check, so a subset it touches is still population B."""
```

```python
"""The production arm: restriction of the clause set, and subset selection.

Spec: `docs/superpowers/specs/2026-10-04-pointwise-oracle-design.md` sections
4 and 5.

This module DOES import production, deliberately: `layer_certify.clauses` is
the thing under test. `build._folded_of` is REUSED rather than retyped,
because an independently written version of exactly that step produced last
slice's defect -- it indexed `polys` where production's `_seg_of` indexes
`result.folded_vertices`, and `layer_order._polys_of` reverses any
negative-area face, which on this subject is 190 of 380.

TWO DEPARTURES FROM THE SPEC, both recorded in the plan:
  1. Subsets are seeded from `Clause.variables`, not from `Prov.faces`:
     `Clause.prov` is a `str` (`layer_certify.py:65`), so `layer_order.Prov`'s
     structural faces do not survive into the clause. The variables carry the
     same faces and do not depend on a message format.
  2. Both populations are defined over the RESTRICTED clause set, not over
     global face membership. Population B asks "does production say nothing
     about THIS neighbourhood", and a clause with one variable outside the
     subset says nothing the oracle can check. Defining B by global membership
     would risk an empty population on a subject carrying 28,192 equalities
     and 74,602 tacos -- a refusal that is an artifact, not a finding.
"""
import os
import sys

_HERE = os.path.dirname(os.path.abspath(__file__))
sys.path.insert(0, os.path.join(_HERE, "..", "..", "..", "..", "mcp_harness"))

import build                           # noqa: E402
import layer_certify                   # noqa: E402

#: The families the enumeration can actually test. `transitivity` is vacuously
#: satisfied by every total order (`_satisfied`'s predicate cannot fail on an
#: acyclic total relation), so it is excluded here and covered instead by
#: `test_restrict.py::test_transitivity_family_rejects_a_cyclic_relation`.
GEOMETRIC_FAMILIES = ("equality", "taco")


def crease_segments(result, K):
    """Every M/V shared edge as `(fa, fb, seg)`, in kernel numbers.

    The index lookup is deliberately identical to `layer_order`'s `_seg_of`
    closure (`:527-531`) and `build`'s `seg_of` (`:91-94`): folded vertices are
    read PER FACE out of `result.folded_vertices`, never out of the clipping
    polygons. The kernel conversion itself is `build._folded_of`, reused.
    """
    folded = build._folded_of(result, K)
    out = []
    for fa, fb, k, a in result.shared_edges:
        if a not in ("M", "V"):
            continue
        face = result.faces[fa]
        i0, i1 = face.index(k[0]), face.index(k[1])
        out.append((fa, fb, (folded[fa][i0], folded[fa][i1])))
    return tuple(out)


def creases_in(creases, subset):
    """The creases with BOTH faces inside `subset`."""
    return tuple((fa, fb, seg) for fa, fb, seg in creases
                 if fa in subset and fb in subset)


def restricted_clauses(all_clauses, subset):
    """Clauses every one of whose variables lies inside `subset`.

    Both directions are tested. Admitting a clause with a variable outside
    would ask the oracle about a face it cannot see; dropping one that is
    wholly inside would weaken the production arm and manufacture agreement.
    """
    return tuple(c for c in all_clauses
                 if all(lo in subset and hi in subset
                        for lo, hi in c.variables))


def order_to_rel(order):
    """`rel[(lo, hi)] = "lo above hi"`, from a top-to-bottom stack.

    `layer_certify._satisfied` pins the convention at `:143`: "rel[(lo, hi)] is
    True means lo above hi". `order[0]` is topmost, so "above" is a SMALLER
    index.
    """
    pos = {f: i for i, f in enumerate(order)}
    faces = sorted(order)
    return {(lo, hi): pos[lo] < pos[hi]
            for i, lo in enumerate(faces) for hi in faces[i + 1:]}


def clause_accepts(clauses_sub, rel):
    """Every restricted clause satisfied under `rel`.

    Evaluated with production's own `_satisfied`, which is the point: the
    production arm must be production's predicate, not a reimplementation of
    it. A literal's value is `rel[pair] != flip` (`Clause`'s docstring,
    `layer_certify.py:56-61`).
    """
    for c in clauses_sub:
        vals = tuple(rel[pair] != flip
                     for pair, flip in zip(c.variables, c.flips))
        if not layer_certify._satisfied(c.family, vals):
            return False
    return True


def classify(all_clauses, subset):
    """`"A"` if production emits a geometric constraint INSIDE `subset`, else
    `"B"`.

    Population A tests soundness (is every constraint real?); population B
    tests completeness (is one missing?). B is the reason the probe exists: a
    run that only visits neighbourhoods where production already found
    something can confirm soundness forever and never detect a missing case.
    """
    for c in restricted_clauses(all_clauses, subset):
        if c.family in GEOMETRIC_FAMILIES:
            return "A"
    return "B"


def candidate_subsets(creases, covers, max_size):
    """One subset per crease: its two faces, grown inside a shared cell cover.

    Seeded from a crease so the oracle always has something to evaluate, and
    grown only with faces that share a cell with the seed, so the additions
    genuinely overlap it -- padding a subset with faces that can never be
    intruders would inflate the order count without strengthening anything.
    A bare crease pair admits only two orders, which no set comparison can
    distinguish, so growth is not optional.

    THE FALLBACK IS LOAD-BEARING, not defensive. A crease's two faces share a
    cell only when their pair survived into `cons.pairs`, and production itself
    guards that with `if tuple(sorted((fa, fb))) in pairs`
    (`layer_order.py:555-558`) -- so some creases have NO cover containing both
    faces. Requiring a cover to contain the whole seed would silently drop
    every such crease and shrink the population without saying so. Covers that
    merely INTERSECT the seed still supply genuinely overlapping faces, so they
    are the correct second choice, and the count of seeds that needed the
    fallback is reported.
    """
    out, seen = [], set()
    for fa, fb, _seg in creases:
        seed = frozenset({fa, fb})
        containing = [c for c in covers if seed <= c]
        pool = containing or [c for c in covers if seed & c]
        best = max(pool, key=len, default=frozenset())
        grown = set(seed)
        for f in sorted(best - seed):
            if len(grown) >= max_size:
                break
            grown.add(f)
        s = frozenset(grown)
        if len(s) < 3 or s in seen:
            continue
        seen.add(s)
        out.append(s)
    return tuple(out)
```

```python
"""Every total order of a subset, both verdicts per order, and the comparison.

Spec: `docs/superpowers/specs/2026-10-04-pointwise-oracle-design.md` section 5.

Imports no production code. The production entry points -- `clause_accepts` and
`order_to_rel` -- arrive as ARGUMENTS, so the injection point is explicit and
this layer stays on the independent side of the boundary.

WHY THE ENUMERATION IS AFFORDABLE. The oracle factors. Breakpoints and covering
sets depend only on geometry, so `stacks.sites` runs the exact rational
arithmetic ONCE per subset and reduces it to a list of `Site`s. Each of the
`|S|!` orders is then decided by integer index comparison. At `|S| = 8` that is
40,320 orders against a handful of sites, with no `Fraction` work in the inner
loop.
"""
from itertools import permutations

import stacks


def all_orders(subset):
    """Every total order of `subset`, top-to-bottom, each exactly once."""
    return tuple(permutations(sorted(subset)))


def rel_to_order(rel, subset):
    """A total order consistent with `rel`, or `None` if there is none.

    `rel` is expected COMPLETE over the subset's pairs, which is what
    `sat_order.SatResult.relation` documents itself to be (`:131`), so this is
    a sort rather than a search: a tournament is transitive exactly when its
    score sequence is 0, 1, ..., n-1, so counting how many faces sit above each
    face both orders them and detects a cycle (a repeated score).

    Returns `None` rather than raising, on either a cycle or a missing pair: on
    the validation reading both are findings to report with their subset, not
    reasons to abort the run.
    """
    faces = sorted(subset)
    above = {f: 0 for f in faces}
    for i, lo in enumerate(faces):
        for hi in faces[i + 1:]:
            if (lo, hi) not in rel:
                return None
            if rel[(lo, hi)]:
                above[hi] += 1
            else:
                above[lo] += 1
    scores = [above[f] for f in faces]
    if len(set(scores)) != len(scores):
        return None
    return tuple(sorted(faces, key=lambda f: above[f]))


def compare(sites_tuple, clauses_sub, subset, clause_accepts, order_to_rel):
    """The set comparison (spec section 5.1).

    Returns both counts AND both difference directions, separately. Not "do
    both say foldable": an existence-only comparison passes a wrong clause set
    whenever at least one valid order survives, and substituting a weaker
    comparison for the designated one is the error this project recorded
    against the previous slice's spec section 4.
    """
    act = stacks.active(sites_tuple)
    for s in act:
        stray = s.cover - frozenset(subset)
        if stray:
            raise ValueError(
                f"site for crease ({s.fa}, {s.fb}) has cover faces "
                f"{sorted(stray)} outside the subset {sorted(subset)}; the "
                f"order would not rank them and the comparison would be "
                f"silently partial")
    orders = all_orders(subset)
    oracle_ok, clause_ok = set(), set()
    for order in orders:
        if stacks.accepts(act, order):
            oracle_ok.add(order)
        if clause_accepts(clauses_sub, order_to_rel(order)):
            clause_ok.add(order)
    return {
        "orders": len(orders),
        "sites_total": len(sites_tuple),
        "sites_active": len(act),
        "oracle_admits": len(oracle_ok),
        "clauses_admit": len(clause_ok),
        "only_oracle": tuple(sorted(oracle_ok - clause_ok)),
        "only_clauses": tuple(sorted(clause_ok - oracle_ok)),
        "identical": oracle_ok == clause_ok,
    }
```

```python
def gate_geometry_fidelity():

    production's arrangement, so a disagreement reported below is about the

def gate_breakpoints_constant(state, subsets, probes_per_segment=3):
    """GATE (spec section 6.1), on REAL geometry rather than a fixture.

    One exact sample per sub-segment is only exhaustive if the covering set is
    constant across it. Measure that: at three distinct interior points of each
    sub-segment the cover must be identical.
    """
    checked = 0
    for subset in subsets:
        for fa, fb, seg in restrict.creases_in(state["creases"], subset):
            others = tuple(sorted(subset - {fa, fb}))
            cuts = stacks.breakpoints(seg, state["polys"], others, K)
            for t_lo, t_hi in zip(cuts, cuts[1:]):
                w = t_hi - t_lo
                ts = [t_lo + w * Fraction(i + 1, probes_per_segment + 1)
                      for i in range(probes_per_segment)]
                covers = {stacks.covering(seg, t, state["polys"], others, K)
                          for t in ts}
                checked += 1
                if len(covers) != 1:
                    raise SystemExit(
                        f"REFUSED: cover is not constant on sub-segment "
                        f"({t_lo}, {t_hi}) of crease ({fa}, {fb}): {covers}. "
                        f"The breakpoint set is incomplete, so one sample per "
                        f"sub-segment is an approximation and every result "
                        f"below would rest on sampling luck.")
    if not checked:
        raise SystemExit(
            "REFUSED: the breakpoint gate examined ZERO sub-segments, so it "
            "certifies nothing. A gate that passes vacuously is worse than no "
            "gate.")
    return checked


def _square(x0, y0, x1, y1):
    """A CCW axis-aligned rectangle in exact rationals."""
    F = Fraction
    return [(F(x0), F(y0)), (F(x1), F(y0)), (F(x1), F(y1)), (F(x0), F(y1))]


def intruder_fixture():
    """Faces 0 and 1 joined by a crease, with face 7 covering its middle.

    Built once and shared by `gate_oracle_refuses` and `selftest`, which both
    need it: two copies of a fixture in one module is two things to keep in
    step.
    """
    F = Fraction
    seg = ((F(0), F(0)), (F(4), F(0)))
    polys = {0: _square(0, -1, 4, 1), 1: _square(0, -1, 4, 1),
             7: _square(1, -1, 3, 1)}
    return stacks.active(stacks.sites([(0, 1, seg)], polys,
                                      frozenset({0, 1, 7}), K))


def gate_oracle_refuses(state, subsets):
    """GATE (spec section 6.4). An oracle never shown to reject is an oracle
    that may be reading nothing.

    Two independent demonstrations: a SEEDED INVERSION of the certified order
    inside a real subset, and the hand-built INTRUDER fixture.
    """
    # (a) the hand-built intruder: face 7 threads a crease between 0 and 1.
    s = intruder_fixture()
    if not s or stacks.accepts(s, (0, 7, 1)):
        raise SystemExit(
            "REFUSED: the oracle ACCEPTED a face placed between a crease's "
            "two faces. It is not implementing the rule it documents.")

    # (b) a seeded inversion of the certified order, in a real subset.
    inverted = 0
    for subset in subsets:
        creases = restrict.creases_in(state["creases"], subset)
        if not creases:
            continue
        act = stacks.active(stacks.sites(creases, state["polys"], subset, K))
        if not act:
            continue
        order = enumerate_orders.rel_to_order(state["rel"], subset)
        if order is None:
            continue
        if not stacks.accepts(act, order):
            continue              # reported separately as a validation failure
        for i in range(len(order) - 1):
            swapped = list(order)
            swapped[i], swapped[i + 1] = swapped[i + 1], swapped[i]
            if not stacks.accepts(act, tuple(swapped)):
                inverted += 1
                break
        if inverted:
            break
    if not inverted:
        raise SystemExit(
            "REFUSED: no adjacent transposition of the certified order was "
            "rejected in any sampled subset, so the oracle has not been shown "
            "to discriminate between orders on this subject's geometry.")
    return {"intruder_rejected": True, "seeded_inversion_rejected": inverted}


def run():
    t0 = time.time()
    state = load_all()
    fidelity = gate_geometry_fidelity()

    cands = restrict.candidate_subsets(state["creases"], state["covers"],
                                       MAX_SUBSET)
    pops = {"A": [], "B": []}
    for s in cands:
        if not restrict.creases_in(state["creases"], s):
            continue
        label = restrict.classify(state["clauses"], s)
        if len(pops[label]) < PER_POPULATION:
            pops[label].append(s)
    exact_arrangement.require_nonempty(population_A=len(pops["A"]),
                                       population_B=len(pops["B"]))

    chosen = pops["A"] + pops["B"]
    bp_checked = gate_breakpoints_constant(state, chosen)
    refusal = gate_oracle_refuses(state, chosen)

    rows, disagreements, validation_failures = [], [], []
    for label in ("A", "B"):
        for subset in pops[label]:
            creases = restrict.creases_in(state["creases"], subset)
            sts = stacks.sites(creases, state["polys"], subset, K)
            cl = tuple(c for c in restrict.restricted_clauses(
                state["clauses"], subset)
                if c.family in restrict.GEOMETRIC_FAMILIES)
            out = enumerate_orders.compare(
                sts, cl, subset,
                clause_accepts=restrict.clause_accepts,
                order_to_rel=restrict.order_to_rel)
            order = enumerate_orders.rel_to_order(state["rel"], subset)
            shipped_ok = None if order is None else stacks.accepts(
                stacks.active(sts), order)
            row = {
                "population": label,
                "subset": sorted(subset),
                "creases": len(creases),
                "clauses": len(cl),
                "shipped_order": None if order is None else list(order),
                "shipped_order_pointwise_ok": shipped_ok,
                **{k: v for k, v in out.items()
                   if k not in ("only_oracle", "only_clauses")},
                "only_oracle": [list(o) for o in out["only_oracle"][:5]],
                "only_clauses": [list(o) for o in out["only_clauses"][:5]],
            }
            rows.append(row)
            if not out["identical"]:
                disagreements.append(row)
            if shipped_ok is False:
                validation_failures.append(row)

    art = {
        "subject": "dense lizard (SAT-certified witness)",
        "kernel": K.name,
        "max_subset": MAX_SUBSET,
        "per_population": PER_POPULATION,
        "gates": {
            "geometry_fidelity": fidelity,
            "sub_segments_cover_constant": bp_checked,
            "oracle_refuses": refusal,
            "population_A": len(pops["A"]),
            "population_B": len(pops["B"]),
        },
        # ⚠ SUPERSEDED: shipped as `families_enumerated`, beside
        # `families_independently_checked: ["equality"]`. `taco` is
        # enumerated but NOT independently checked -- design doc
        # limitation 12. Do not copy this key name.
        "families_under_test": list(restrict.GEOMETRIC_FAMILIES),
        "families_not_under_test": ["transitivity"],
        "subsets": rows,
        "disagreements": disagreements,
        "validation_failures": validation_failures,
        "verdict": ("identical" if not disagreements and
                    not validation_failures else "DISAGREEMENT"),
        "elapsed_secs": round(time.time() - t0, 1),
    }
    out_path = os.path.join(_HERE, "pointwise-oracle.json")
    with open(out_path, "w") as fh:
        json.dump(art, fh, indent=2, sort_keys=True)
    print(json.dumps({k: v for k, v in art.items() if k != "subsets"},
                     indent=2, sort_keys=True))
    print(f"\nwrote {out_path}")
    return art


def selftest():
    """Every gate demonstrated to REFUSE, not merely to be present."""
    checks = []

    # 1. `sites` refuses a crease with a face outside the subset.
    F = Fraction
    try:
        stacks.sites([(0, 99, ((F(0), F(0)), (F(1), F(0))))],
                     {0: _square(0, 0, 1, 1)}, frozenset({0}), K)
        checks.append(("sites refuses a stray face", False))
    except ValueError:
        checks.append(("sites refuses a stray face", True))

    # 2. `compare` refuses a cover face outside the subset.
    try:
        enumerate_orders.compare(
            (stacks.Site(0, 1, frozenset({42}), F(0), F(1)),), (),
            frozenset({0, 1}),
            clause_accepts=lambda cl, rel: True,
            order_to_rel=restrict.order_to_rel)
        checks.append(("compare refuses a stray cover face", False))
    except ValueError:
        checks.append(("compare refuses a stray cover face", True))

    # 3. `require_nonempty` refuses an empty population.
    try:
        exact_arrangement.require_nonempty(population_B=0)
        checks.append(("require_nonempty refuses an empty population", False))
    except SystemExit:
        checks.append(("require_nonempty refuses an empty population", True))

    # 4. the oracle rejects the hand-built intruder.
    s = intruder_fixture()
    checks.append(("oracle rejects an intruder between a crease's faces",
                   bool(s) and not stacks.accepts(s, (0, 7, 1))))

    # 5. the breakpoint gate fails on a coarsened cut list.
    seg = ((F(0), F(0)), (F(6), F(0)))
    one = {7: _square(1, -1, 3, 1)}
    covers = {stacks.covering(seg, t, one, (7,), K)
              for t in (F(1, 8), F(1, 2), F(7, 8))}
    checks.append(("coarsened cuts give a NON-constant cover",
                   len(covers) != 1))

    # 6. `transitivity` rejects a cycle.
    checks.append(("transitivity rejects a cyclic triple",
                   not layer_certify._satisfied("transitivity",
                                                (True, True, False))))

    # 7. `rel_to_order` returns None on a cycle.
    checks.append(("rel_to_order detects a cycle",
                   enumerate_orders.rel_to_order(
                       {(0, 1): True, (1, 2): True, (0, 2): False},
                       frozenset({0, 1, 2})) is None))

    for name, ok in checks:
        print(f"{'PASS' if ok else 'FAIL'}  {name}")
    bad = [n for n, ok in checks if not ok]
    if bad:
        raise SystemExit(f"\n{len(bad)} selftest check(s) FAILED: {bad}")
    print(f"\nselftest: {len(checks)}/{len(checks)} checks pass")


def main():

    ap.add_argument("--selftest", action="store_true",
                    help="demonstrate every guard refusing, and exit")
    args = ap.parse_args()
    if args.selftest:
        selftest()
    else:
        run()
```
